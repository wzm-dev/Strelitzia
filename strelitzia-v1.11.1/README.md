# Strelitzia 👑

Hub para Roblox com ESP, Aimbot, Fly, Themes e mais — por **Eodraxkk & Einzbern**.

## 🚀 Como usar

Cole no seu executor:
```
loadstring(game:HttpGet("https://raw.githubusercontent.com/wzm-dev/Strelitzia/main/loader.lua"))()
```

## ✨ Destaques

- **ESP completo**: box 2D, health bar, info, bones, chams, team colors
- **Combat**: aimbot (comum/rage), silent aim, trigger bot, kill aura, auto parry
- **Movement**: fly, noclip, walk on walls, bunny hop, infinite jump
- **Server Picker**: escolha o server por players/ping (mais vazio / mais cheio)
- **QuickBar**: barra de ações rápidas estilo Sirius
- **Tema Strelitzia**: roxo-royal + ouro com bg animado e borda dourada girando
- **Persistente**: re-executa automático ao trocar de mapa
- **.cmds**: comandos de chat (.fly, .tp Nome, .panic...)

## ⚙️ Requisitos

- Executor com `loadstring` + `HttpGet` (Synapse Z, Wave, Swift, etc.)
- Suporte PC e Mobile
